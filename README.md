# Physics Toolkit

Physics Toolkit is an educational Python library developed as part of my transition from Physics student to software developer.

Its goal is to build reusable, well-tested modules for introductory physics, numerical methods and scientific computing while following modern Python development practices.



## Why this project?

Instead of creating isolated scripts while learning Python, I want to build a real software project that grows over time.

This repository will become the foundation for future simulation, data analysis and computational physics projects.



## Current Status

This project is in its initial development stage.

The project structure has been initialized using:

- uv
- src layout
- modern pyproject.toml
- Git
